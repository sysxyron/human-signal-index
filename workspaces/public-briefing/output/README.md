# Public Briefing — Output

Outputs of the Public Briefing stage: public-safe briefings, citation lists, and
traceability notes. Briefings here become public **only** after the publishing
checklist and traceability gate pass.

## What lands here

| File / shape | Contents |
| --- | --- |
| `public-briefing-<date>.md` | The neutral, cited public briefing document. |
| `citations.json` | Public, verifiable source citations referenced by the briefing. |
| `traceability-notes-<date>.json` | Traceability score, threshold (0.72), per-claim verdicts, reviewer id. |
| `example-briefing.md` | Worked, neutral example of a public briefing. |

## Rules

- Only approved, cited material; raw private evidence stays private.
- Safe-framing + vulnerable-audience care required.
- Correction/takedown contact must be reachable from the public page.

Example: `public-briefing-2026-06-06.md`, `citations.json`, `example-briefing.md`.
