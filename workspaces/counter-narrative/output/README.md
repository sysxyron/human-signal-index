# Counter-Narrative — Output

Outputs of the Counter-Narrative stage: safe, source-backed educational explainers
drafted from reviewed analysis. Drafts only — nothing here is public.

## What lands here

| File / shape | Contents |
| --- | --- |
| `counter-narrative-<date>.md` | Explainer using the safe-framing structure (claims / assumes / leaves out / who is vulnerable / how to respond / debate questions / context). |
| `educational-notes-<date>.json` | `signal_id`, `generated_content` id, citations, traceability status, `ai_run` id + prompt version, reviewer id, safe-framing checklist result. |

## Rules

- Non-defamatory and mental-health-safe; addresses ideas, not private people.
- Paraphrase dangerous/operational text; never amplify.
- Cite every factual claim; carry traceability status.

Example: `counter-narrative-2026-06-06.md`, `educational-notes-2026-06-06.json`.
